# Coding Questions

This folder contains coding-practice files used for interview preparation.

| File                           | Purpose                                                              |
| ------------------------------ | -------------------------------------------------------------------- |
| `weekly_deployment_windows.py` | Runnable Python solution for the deployment-window interval problem. |
| `python_coding_questions.py`   | Python coding patterns and practice problems.                        |
| `libraryMngmnt.py`             | Object-oriented library management example.                          |
| `java_coding_questions.java`   | Java coding question examples.                                       |

## Suggested workflow

1. Read the problem statement.
2. Explain the approach out loud.
3. Write a clean solution.
4. Add edge cases.
5. Discuss time and space complexity.

For broader topic explanations, use the Markdown notes in `docs/`.
