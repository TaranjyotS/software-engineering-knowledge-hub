# Coding Questions

This folder contains runnable, interview-focused coding exercises. Each exercise is self-contained: the question is kept directly in the source file using the same readable block-comment/docstring style as `libraryMngmnt.py`, followed by the implementation, examples or tests, and an explanation where appropriate.

## Suggested Workflow

1. Open the runnable source file and read the question block directly above the implementation.
2. Explain the approach out loud before reading the implementation.
3. Reimplement or modify the solution yourself.
4. Add edge cases and discuss time and space complexity.
5. Run the included sample tests.

For broader topic explanations, use the Markdown notes in `docs/`.
